# Silent Hill 2: Mira's Edition
# Silent Hill 2 Open Port (Rust)

An open-source, memory-safe, modern game engine port of **Silent Hill 2 (Director's Cut / Restless Dreams)** written in **Rust**, targeting **Linux** and the **AYN Thor** dual-screen Android handheld.

## Key Features
- **Unrestricted from Emotion Engine Limits:** High-precision 32-bit floating-point depth buffer, GPU compute-shader volumetric fog, and decoupled 60+ FPS simulation.
- **Dual-Screen Companion UI:** Form-fitted for the AYN Thor clamshell, featuring an interactive real-time town map, one-tap healing quick-slots, memo viewer, and built-in developer console on the lower screen.
- **Full Scenario Support:** Supports both the main campaign (*Letter from Silent Heaven*) and Maria's sub-scenario (*Born from a Wish* in the Baldwin Mansion).
- **Prototype Rosetta Stone:** Incorporates unstripped debug symbols and collision/lighting visualizers from the July 13, 2001 and E3 2001 prototype builds.
- **Enhanced Edition Compatible:** Fully ingests SH2:EE widescreen fixes, 1080p60 FMVs, high-resolution font packs, and restored audio scripts.
